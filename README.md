# AI Chatbot - Spring Boot

An AI-powered chatbot built using Spring Boot and the Groq API. 
The application allows users to send messages and receive AI-generated responses through a simple web interface.

## Features

- AI-powered conversational chatbot
- Real-time message and response flow
- Groq API integration
- REST API using Spring Boot
- Simple and user-friendly web interface
- Environment variable based API key configuration
- Docker support
- CI pipeline using GitHub Actions
- Continuous deployment using Render
